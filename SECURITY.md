# Security Policy

## Supported Versions

We currently support the latest version of the repository.

| Version | Supported          |

## Reporting a Vulnerability

If you find any security vulnerabilities or issues, please report them by opening a GitHub Issue or contacting the maintainers directly. We take security seriously and will respond to reports as quickly as possible.
