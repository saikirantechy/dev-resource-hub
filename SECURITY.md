# Security Policy

## Supported Versions

We actively maintain the current `main` branch. Please ensure you are using the latest version of the platform.

| Version | Supported          |
| ------- | ------------------ |
| v1.x    | :white_check_mark: |
| < v1.0  | :x:                |

## Reporting a Vulnerability

We take the security of our ecosystem seriously. If you find a security vulnerability, please do NOT open a public issue. Instead, report it privately.

**How to report:**
1. Send an email to [insert-security-email-here].
2. Include a detailed description of the vulnerability.
3. Provide steps to reproduce (if applicable).
4. Mention any potential impact.

We will acknowledge your report within 48 hours and provide a timeline for a fix.

## Policy

- We will not pursue legal action against researchers who report vulnerabilities in good faith.
- We request that you do not disclose the vulnerability publicly until a fix has been released.
