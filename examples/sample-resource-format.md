# Sample Resource Format

Use this format when adding a new resource to any category file.

```md
- **Resource Name** – A brief, one-sentence description of what this tool or resource does. Focus on the value it provides to developers.
  🔗 [https://link-to-resource.com](https://link-to-resource.com)
```

## Example:

- **VS Code** – A highly customizable and powerful source-code editor developed by Microsoft.
  🔗 [https://code.visualstudio.com](https://code.visualstudio.com)
