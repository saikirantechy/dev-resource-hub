# ⚙️ DevOps

Tools for containerization, orchestration, CI/CD, and infrastructure management.

---

- **Docker** – Containerization platform to build, share, and run applications  
  🔗 [https://www.docker.com](https://www.docker.com)

- **Kubernetes** – Container orchestration system for automating deployment and scaling  
  🔗 [https://kubernetes.io](https://kubernetes.io)

- **GitHub Actions** – CI/CD automation directly in your GitHub repository  
  🔗 [https://github.com/features/actions](https://github.com/features/actions)

- **Jenkins** – Open-source automation server for building CI/CD pipelines  
  🔗 [https://www.jenkins.io](https://www.jenkins.io)

- **Terraform** – Infrastructure as Code tool for provisioning cloud resources  
  🔗 [https://www.terraform.io](https://www.terraform.io)

- **Ansible** – Automation tool for configuration management and deployment  
  🔗 [https://www.ansible.com](https://www.ansible.com)

- **Amazon Web Services** – Comprehensive cloud platform for all your DevOps needs  
  🔗 [https://aws.amazon.com](https://aws.amazon.com)

- **AWS CloudWatch** – Monitoring and observability service for AWS resources  
  🔗 [https://aws.amazon.com/cloudwatch](https://aws.amazon.com/cloudwatch)

- **Prometheus** – Open-source monitoring and alerting toolkit  
  🔗 [https://prometheus.io](https://prometheus.io)

- **Grafana** – Visualization and dashboard platform for metrics and logs  
  🔗 [https://grafana.com](https://grafana.com)

- **Argo CD** – GitOps continuous delivery tool for Kubernetes  
  🔗 [https://argo-cd.readthedocs.io](https://argo-cd.readthedocs.io)
