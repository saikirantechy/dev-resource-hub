# DSA Arena — User Guide

## Getting Started

### 1. Visit the DSA Arena Hub
Navigate to `/dsa` to see the main hub with mode selection, stats, and quick links.

### 2. Choose Your Mode

**Tutor Mode** (`/dsa/tutor`)
- Ask the AI Tutor about any DSA concept
- Use quick actions: Explain Concept, Show Hint, Code Example, Complexity Analysis
- Browse suggested topics and track your progress

**Assessment Mode** (`/dsa/assessment`)
- Start the AI Examiner ("Dave") assessment
- Answer MCQs, coding problems, debugging questions
- Get scored with detailed feedback and improvement areas

### 3. Join the Arena (`/dsa/arena`)
- Join a room using a room key
- Create your own room with custom settings
- Browse public rooms by status (Active/Upcoming/Ended)
- Use the live code editor to write and test solutions

### 4. Track Your Progress
- **Leaderboard** (`/dsa/leaderboard`): See top players globally or filter by college/friends
- **Rankings** (`/dsa/rankings`): View tier distribution (Bronze → Legend)
- **Achievements**: Unlock 6 achievements as you progress

### 5. Learn Systematically
- **Roadmaps** (`/dsa/roadmaps`): Follow structured learning paths
- **Topics** (`/dsa/topics`): Browse 24 DSA topics with progress tracking
- **Challenges** (`/dsa/challenges`): Solve 12 curated problems with company tags

## Tips
- Start with Tutor Mode if you're new to a concept
- Use Assessment Mode to simulate real interview conditions
- Check the Leaderboard for motivation
- Follow Roadmaps for structured learning
- Use the Code Editor in Arena to practice writing solutions
