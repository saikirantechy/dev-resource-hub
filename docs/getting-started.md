# 🚀 Getting Started

Welcome to the Dev Resource Hub! Here's how you can get the most out of this project.

## 📖 Browsing Resources
1. Explore the `categories/` folder to find tools for your specific needs.
2. Each category file contains a curated list of tools with links and short descriptions.
3. Click the links to visit the official websites of the resources.

## 🤝 How to Help
This project is built by the community. If you know of a great tool that isn't listed, please contribute!

1. Read the [Contributing Guide](../CONTRIBUTING.md).
2. Follow the [Code of Conduct](../CODE_OF_CONDUCT.md).
3. Open a Pull Request or suggest a resource via an [Issue](https://github.com/saikirantechy/dev-resource-hub/issues).

## 🌟 Support Us
- **Star** this repository to show your support.
- **Fork** the repo to keep your own copy of the resources.
- **Share** with your friends and colleagues!
