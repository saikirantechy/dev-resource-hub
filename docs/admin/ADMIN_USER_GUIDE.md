# Admin User Guide

## Getting Started

### First-Time Setup
1. Navigate to `/admin/setup`
2. Complete the Setup Wizard to create your Super Admin account
3. You'll be redirected to the Admin Dashboard

### Login
1. Go to `/admin/login`
2. Enter your admin credentials
3. You'll be redirected to the Dashboard

## Dashboard Overview
The Dashboard displays:
- Total content items across all categories
- Quick stats for each module (Users, Blogs, Tools, Agents, etc.)
- Quick Actions panel for common tasks
- Recent Activity feed showing admin actions

## Management Modules

### Users
- View all platform users with XP, rank, and contribution stats
- Search and filter users
- Manage user roles and permissions
- Suspend/deactivate users

### Blogs
- View all blog posts and prompts
- Search by title, description, or category
- Create, edit, and delete content
- Feature or star important posts

### Tools & Agents
- View all AI tools and agents
- Manage featured and trending status
- Track stars and views

### Events
- View all platform events
- See dates, locations, and attendee counts
- Create and manage event listings

### Analytics
- View platform metrics and traffic sources
- Track user growth over time
- See top-performing pages

### Settings
- Configure site name, description, and branding
- Manage SEO settings
- Toggle features on/off
- Set up analytics integrations

### Activity Logs
- View all admin actions with timestamps
- Filter by action type
- Search logs
- Clear log history
