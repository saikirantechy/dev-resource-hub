# Open Source Opportunities Hub — User Guide

## Getting Started

### Finding Your First Issue
1. Go to the **Open Source Hub** (`/open-source`)
2. Click **Explore Issues** to open the GitHub Issues Explorer
3. Use the search bar to find issues by keywords
4. Filter by language, difficulty, or sort order
5. Click **Good First Issues** to find beginner-friendly tasks
6. Click any issue card to open it on GitHub

### Using the AI Issue Explainer
1. Scroll to the **AI Issue Explainer** section on the Issues page
2. Paste a GitHub issue URL (e.g., `https://github.com/owner/repo/issues/123`)
3. Click **Analyze**
4. View the summary, difficulty rating, skills needed, and estimated time

### Generating a Contribution Roadmap
1. Navigate to **AI Contribution Coach** (`/ai-contribution-coach`)
2. Select your experience level (Beginner, Intermediate, Advanced)
3. Select your goal (First PR, GSoC Prep, Portfolio, Career, etc.)
4. Click **Generate My Roadmap**
5. Get your personalized AI-powered contribution plan

### Exploring GSoC Opportunities
1. Go to **GSoC Hub** (`/gsoc`)
2. View the program overview and timeline
3. Explore AI-powered tools (Proposal Generator, Organization Matcher)
4. Read application tips
5. Visit the official GSoC site to apply

### Finding Open Source Bounties
1. Go to **Bounties** (`/bounties`)
2. Filter by difficulty and reward range
3. Search by repository or issue name
4. Click on any bounty to open the issue on GitHub

### Tracking Your Contributions
1. Go to **My Contributions** (`/my-contributions`)
2. Connect your GitHub account
3. View your stats, achievements, and recent activity
4. Track your progress on the leaderboard

### For Maintainers
1. Go to **Maintainer Hub** (`/maintainers`)
2. Submit your repository to the directory
3. Highlight specific issues that need contributors
4. View contributor analytics and community insights

## Tips
- **Start small** — Fix documentation or small bugs first
- **Be consistent** — Contribute regularly to build momentum
- **Engage** — Join community discussions and ask questions
- **Track progress** — Use My Contributions to monitor your growth
- **Set goals** — Use the AI Coach to plan your journey
